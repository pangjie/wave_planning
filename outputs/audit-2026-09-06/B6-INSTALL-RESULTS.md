## 检查依据与调整

- 现有 Python 为 3.12.14；实际环境 `pip check` 返回 `No broken requirements found`。
  pytest 8.4.0 满足已安装 pytest-asyncio 1.0.0 的 `pytest>=8.2,<9` 约束。
  未发现需要升级固定包版本的已复现兼容冲突，不升级 pip、浏览器或 PDF 工具链。

  现在安装前检查解释器；已存在的虚拟环境直接复用，损坏或过旧则提示并退出，

  三个包移到 `requirements-dev.txt`，通过 `-r` 引用运行清单；桌面构建清单也引用运行清单。
  所有原固定版本不变，默认安装运行依赖，`setup.sh --dev` 加装测试依赖，不卸载旧包。
- 安装后增加 `pip check`。安装/兼容检查失败不输出完成提示。
  新增参数帮助与未知参数拒绝，更新两份 README 的安装、测试和解释器说明。
